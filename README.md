## 🏢 Visitor Appointment Tracking System
[![Visitor-Tracking.png](https://via.placeholder.com/800x450.png?text=Visitor+Appointment+Tracking+System)](ลิงก์รูปภาพตัวเต็มของคุณ)

โปรเจกต์นี้พัฒนาด้วย **Vue.js, Node.js, SQL Server** และ **Leaflet.js** มีจุดประสงค์เพื่อเพิ่มประสิทธิภาพใน **การบริหารจัดการนัดหมาย** และ **ติดตามตำแหน่งแบบเรียลไทม์** ภายในพื้นที่อาคาร  
โดยนำเสนอในรูปแบบโปรแกรมประยุกต์บนเว็บ (Web Application) แบบ Full-Stack  
ระบบนี้ประยุกต์ใช้เทคโนโลยี **Bluetooth Beacon** ทำงานร่วมกับระบบแจ้งเตือน **Firebase (FCM)** ซึ่งเจ้าหน้าที่จะได้รับการแจ้งเตือนทันทีเมื่อผู้มาติดต่อเดินทางมาถึง และสามารถตรวจสอบพิกัดได้อย่างแม่นยำผ่านแผนที่จำลอง
